# NG126 — Local Milnor data do not produce analytic syzygies

- **Route:** obtain B156's all-order syzygies from fixed ODP Hessians, local
  \(A_1\) Milnor lattices, or the individual Picard--Lefschetz reflections.
- **Valid input:** these invariants control each node's local vanishing
  cycle and monodromy operator.
- **Invalid inference:** they constrain higher analytic relations among the
  node critical values on the parameter base.
- **Precise obstruction:** B157 realizes every analytic \(\tau\) while
  keeping all those local data fixed. In particular, choose

  \[
  \tau_m(x,y)=(x,x+y^m),\qquad m\ge3.
  \]

  Its ideal is \((x,y^m)\), its hidden-generator space is generated by
  \(y^m\), and the differential relation \((1,-1)\) has no analytic
  syzygy lift with that value at the origin.
- **Scope guard:** B157 uses a generally nonlinear analytic pullback into a
  projective complete linear system. It does not exclude a theorem using
  the global linear structure of the full universal incidence germ.
- **Re-entry condition:** prove G100 from that full-linear-system geometry,
  the superlinear matroid package, and the specified detector pairing—not
  from nodewise Milnor data alone.
