# NG151 — A global Lagrangian need not split by node

Let \(H\) be a \(2n\)-dimensional complex vector space with a
nondegenerate symmetric form \(B\). Put

\[
 G_1=G_2=H,\qquad
 E(\mathbf C)=\mathbf C(1,1)\subset\mathbf C^2.
\]

The value matroid is \(U_{1,2}\), and its relation space is generated by
the full-support vector

\[
 c=(1,-1).
\]

The corresponding B187 form on \(G_1\oplus G_2\) is

\[
 q_c((v_1,v_2),(w_1,w_2))
 =B(v_1,w_1)-B(v_2,w_2). \tag{1}
\]

Consider the diagonal subspace

\[
 U=\{(v,v):v\in H\}.
\]

Equation (1) vanishes identically on \(U\times U\), and

\[
 \dim U=2n=nN.
\]

Thus \(U\) saturates B187's global Lagrangian ceiling. Nevertheless both
coordinate projections

\[
 U\longrightarrow G_i
\]

are isomorphisms. The image is not contained in
\(\Lambda_1\oplus\Lambda_2\) for any nodewise maximal isotropics
\(\Lambda_i\subsetneq G_i\), and it has no positive-dimensional kernel
under either node projection.

## Consequence

One full-support relation yields a global Lagrangian condition, not the
split conormal core of B147-G093 and not isotropy for every value relation.
G120 must construct only what B187 proves necessary; any nodewise splitting
requires a separate geometric mechanism.
