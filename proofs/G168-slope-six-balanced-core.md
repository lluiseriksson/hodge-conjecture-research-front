# G168 — Construct the slope-six balanced core

B244 closes every degree-two quadric layer below slope six for even
dimensions \(d\ge8\). The next balanced signature is

\[
 m=2,\qquad s=6d,\qquad \delta_1=3d, \tag{1}
\]

with

\[
 N=8d+2,\qquad h_Z(1)=4d+1=N/2,\qquad
 s-2\delta_1=0. \tag{2}
\]

The relation transport is an isomorphism and the degree-one code is
diagonally self-dual. B244 excludes every nonstandard quadric
polarization even beyond this exact rank until \(s\ge6d+6\), but the
standard polarization must be re-audited at \(h_Z(1)=4d+1\).

G168 remains only a sufficient specialization of G148. No marked
scheme, ODP package, rational detector, specified pairing, algebraic
cycle, proof, or disproof of HC is currently constructed.
