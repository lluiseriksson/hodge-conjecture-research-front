# B183 — Unit invariance of the conormal escape defect

Let \(O=\mathcal O_{F_B,0}\), and write the escape ideal as

\[
 K=(\epsilon_1,\ldots,\epsilon_s).
\]

Choose arbitrary units \(h_i\in O^\times\) and set

\[
 n_i=h_i\epsilon_i. \tag{1}
\]

Then

\[
 (n_1,\ldots,n_s)=(\epsilon_1,\ldots,\epsilon_s)=K, \tag{2}
\]

because each \(h_i\) is invertible.

Differentiate (1):

\[
 dn_i=h_i\,d\epsilon_i+\epsilon_i\,dh_i.
\]

The second term belongs to \(K\Omega^1_O\). Hence B179's conormal map
satisfies

\[
 \beta_K([n_i])
 =\overline{h_i}\,\beta_K([\epsilon_i])
 \quad\text{in}\quad
 \Omega^1_O\otimes O/K. \tag{3}
\]

The scalar \(\overline{h_i}\) is a unit in \(O/K\). Therefore clearing
unit denominators preserves:

1. the ideal \(K\);
2. vanishing or nonvanishing of \(\beta_K\);
3. the vanishing order of every nonzero conormal row;
4. the jet order at which the first nonzero coefficient appears.

In particular, if

\[
 \epsilon_i=\frac{n_i}{h_i},\qquad h_i(0)\ne0,
\]

the effective conormal gate may work with the numerators \(n_i\) after
certifying that the \(h_i\) are units. It does not need the Taylor series
or a jet bound for \(h_i^{-1}\).

## Exact model

For

\[
 \epsilon_m(y)=\frac{y}{1-y^m},
\]

the denominator inverse first varies in order \(m\), but

\[
 (\epsilon_m)=(y)
\]

and

\[
 \beta_{(y)}([y])=dy\pmod y
\]

is visible in order zero for every \(m\).

## Scope guard

B183 removes inverse-unit Taylor complexity from the conormal order
calculation. It does not bound the algebraic numerator functions obtained
from the labelled critical algebra, nor prove their required jets vanish.
